Walk a watch-an-ad reward task on the current app: tap the task entry, sit through the ad, claim, then repeat for the next step. Give taskText for the entry to tap, claimText when the app words its buttons differently. The ad's close control is an icon rather than text, so it is found by its accessibility name (for one supplier, `点击退出关闭视频`) instead of OCR, and the call-to-action comes from the lowest line of on-screen text; the ad counts as shown once the task entry disappears, and after the video it taps the ad's call-to-action, then waits out the required seconds on whatever prompt comes up. A jump or permission prompt counts as the click the ad rewards, so it waits on that prompt and cancels or declines it — the user never lands in the other app and nothing is granted; if the phone really did switch apps, it only presses back and does not touch that app's screen. A missing entry, an ad that never appears, or a used-up round budget ends the run with a stopped reason. One round does one thing — claiming spends a round too — so nine steps needs rounds 18 or the run stops halfway. The screen changes while it runs.
