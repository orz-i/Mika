Run an app script that ships inside an app plugin package: `plugin.json` may carry `flows`, small declarative scripts made of find/tap/wait/sleep/back/if/repeat steps. They drive the current screen through the same phone actions a person would use, so cancellation, screen guards and action logging match single-step calls. Leave `flow` empty when the app has one script; pass an id to choose among several. `params` is a JSON object filled into the script's `${name}` placeholders, e.g. `{"rounds":2}`. A missing target ends the run with `not_found` unless the step is optional; a script can also stop itself with a reason such as `ad_not_shown`. The reply lists every executed step, so you can see which one failed. Scripts live in the plugin package — to change where it taps, edit the package and run again; nothing needs rebuilding.
