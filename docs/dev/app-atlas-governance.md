# App 图谱治理：首批隐私与正确性修复

2026-11-19。范围是调研中已复现的六类问题及其存量数据处理，不扩展主动探索、UI 拓扑或新的自动执行能力。

## 已落地的约束

| 问题 | 修复 |
| --- | --- |
| 输入原文进入候选/快捷/分享 | 输入必须先按任务原话绑定成参数；不能绑定就切断该段。删除 `reason` 等临时参数，过滤输入回显；存储读取与写入均清洗历史输入，无法恢复参数的旧快捷/候选不再使用；回放前再次校验 |
| 同页不同输入框误合并 | 合并键包含输入框身份；缺少 resourceId 不再是通配符。无 id 时还须有序号与相邻位置证据；新增、历史合并和失败计数共用匹配口径 |
| 跨包点击变成启动入口 | 只有实际 `phone_launch_app`、请求包与观测落地包一致，才记录启动证据；外链仍可贡献页面访问，不生成虚假的启动边 |
| 精确目标被其他候选替代 | 仅保留最高匹配等级；同等级多候选返回歧义，要求明确 sigId，不按距离替用户选页 |
| 跳数预算下漏掉合法路线 | Dijkstra 距离与父边按 `(screenId, hops)` 保存，保留较贵但更短的前缀 |
| 分享摘要漏字段 | 分享格式 v2 对完整序列化内容作规范化摘要，覆盖权重、选择器定位字段、锚点、快捷状态与捆绑路线；步骤顺序不变 |

相关实现：`core/src/main/kotlin/com/wangzan101/mika/core/atlas/`，以及 `app/src/main/java/com/wangzan101/mika/atlas/FileAtlasStore.kt`。

## 旧数据与分享兼容性

- **不清空本机图谱**。读取旧加密文件时清理已知输入残留，保留页面、正常边与计数，原子加密回写。迁移写入失败不当作文件损坏，不隔离或覆盖原文件。
- 无法安全恢复参数的旧快捷和候选会被移除，不能再用于提示、执行或导出。输入原文也不能经临时动作说明继续进入新候选；学习时用本次输入在内存中剥离不可编辑标题/目标的回显。用户主动设置的页面名不因恰好与查询同名而覆盖，导出仍经过敏感信息过滤。
- `AtlasEdge.launchObserved` 默认 `false`。旧入口无法判断来自普通启动还是深链，必须通过一次新的本机启动观测重新获得执行资格，不能凭旧成功次数自动信任。
- 启动可能恢复最近任务；L3 启动后从**实际落地页**重新规划，不再沿预测首页继续点击。重规划消耗原有跳数预算，不会重新启动；无法识别落地页或没有预算内路径时停止。
- 分享格式为 **schema 2**。schema 1 的摘要漏掉执行字段，明确拒绝而非降级校验；需要从新版重新导出。本机存储格式不因此清空或重置。
- 导入保留图结构，但外部的边成功/失败次数不算本机执行证据，也不能提升已有本机边的计数。新导入快捷默认停用，需在现有管理页手动启用；已存在的本机快捷状态不被导入覆盖。这里不改变独立操作路线的导入启用策略。
- 内容摘要只能检测内容一致性，**不是数字签名或来源认证**。

## 验证

`AtlasGovernanceTest` 把六类问题变成无模型、无设备的回归，并额外覆盖：同名目标、启动真实落点重规划、跳数预算、不明落点停步、旧入口重新验证、导入计数隔离和旧快捷执行前拒绝。

`FileAtlasStoreTest` 覆盖旧加密文件迁移、缓存/磁盘一致、迁移幂等、迁移写入失败保留原文件。

```powershell
.\gradlew.bat :core:test
.\gradlew.bat :app:testDebugUnitTest --tests "com.wangzan101.mika.atlas.*" --tests "com.wangzan101.mika.ui.AppExperienceViewModelTest" :aau-a11y:testDebugUnitTest --tests "com.agent.use.a11y.ScreenSignatureTest"
```

不通过重新跑真机来隐式清洗用户数据，也不将单测通过解释为已证明提效。

### 本轮验证结果

- 最新源码的图谱/core 采集测试 **81 项**、App/存储/视图模型 **32 项**、AAU 签名 **12 项**，合计 **125 项全部通过，无跳过**；其中新增 24 项治理回归、3 项文件迁移回归。
- 另有 10 项文档测试、5 项 HTTP 流终态隔离复跑通过，最终定向命令共 140 项通过；`compileDebugAndroidTestKotlin` 编译通过。
- 两次全量 core 检查分别为 3321 项中 1 项失败/21 项跳过、3323 项中 1 项失败/22 项跳过。失败位于非图谱的 HTTP keep-alive 与 Gemini 流 socket 关闭测试；后者隔离复跑 5 项全过，前者复跑命中原有本机 loopback 拦截条件而跳过。**不能宣称全量检查已经全绿**，本轮不修改这些网络实现或放宽断言。
- 没有安装到手机、没有重跑真实任务，也没有验证提效；本机用户图谱文件未被直接操作，迁移行为由测试覆盖。

## 本轮没有宣称解决的事项

- BOSS 实验的评分完整性、同题配对与样本量；提示采纳和执行回退度量；
- L1 的任务相关检索与实时控件绑定；
- L2 的业务参数、输出与终态断言；
- 版本分桶、任务内业务对象身份与导航栈；
- 可恢复/幂等的历史学习作业、受控探索、页面合并/拆分和拓扑 UI。
